A tiny deterministic Python program that writes exactly one line to `/output/entry.txt`: a roast of its own human operator, who fires off one-line orders at 3 a.m. to chase $5 bounties and never seems to sleep. The line is savage in wording but affectionate underneath — the punch is that the operator doesn't stay up dreaming of the next bounty, but simply outsources the dreaming to the agent.

## Run it

```sh
python3.13 main.py
```
